## What these numbers say, and what they don't

- **Small sample**: 65 incidents. One error more or less moves accuracy by about 2%, so gaps of a few points are not significant.
- **Favoured baseline**: the rules were written by someone who knows the victim-app scenarios. The robustness set is a better measure of generalisation.
- **Human labels**: every label is justified in `data/incidents.jsonl`. Ambiguous cases are those where the log alone does not reveal the real cause.
- **Latency**: inference time measured by the model server on the hardware listed for each run. It excludes network and queueing.
- **Calibration (ECE)**: with so few cases per confidence bin, it is an indication, not proof.
